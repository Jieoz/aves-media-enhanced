## Aves Media Enhanced 1.0.4

本版本完成 1.0.3 发布后的全仓审计修复，重点关闭外部搜索隐私、增量刷新漏变更、部分媒体权限误删和异步任务永久等待风险。

### 核心修复

- **Vault 不再进入外部全局搜索结果**：搜索建议数据库查询明确排除 Vault 来源条目。
- **单个及非整批 URI 刷新不再越界**：最后一批增量刷新按真实列表长度截断。
- **MediaStore generation 不再跨过并发变化**：查询前捕获上界，只在查询成功后提交该水位；期间的新变化留到下一轮。
- **Android 14 部分照片权限 fail-closed**：选中照片模式形成的不完整 MediaStore 视图不再被当作删除证据。
- **同 key 媒体请求不再永久等待**：运行中的请求共享 Future，被替换的排队任务显式取消。
- **目录名中的 `%` 和 `_` 按普通字符处理**：SQLite `LIKE` 前缀查询增加转义，避免混入兄弟目录。
- **图片失败路径可结束且资源可释放**：调色板解码错误会完成 Future；GeoTIFF 源图像及 Android Cursor 在成功、空结果和异常路径均正确释放。

### 构建与供应链

- GitHub Actions 固定到经过核验的完整 commit SHA。
- Dependabot 增加 7 天更新冷却期。
- 云端继续执行 Flutter Analyze、Flutter 测试、MediaStore 合约测试和 Android 单元测试。
- 3 个 ABI 的正式签名 APK 均检查包名、版本、versionCode、签名证书、ABI 纯度、ZIP 完整性和 SHA-256。
