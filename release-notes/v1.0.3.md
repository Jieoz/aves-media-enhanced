## Aves Media Enhanced 1.0.3

这次把 1.0.2 后仍未关闭的审计项一并收尾，重点是避免图库同步竞态和任何“无法确认却按删除处理”的路径。

### 核心修复

- **全量重扫与增量刷新串行化**：两条路径不再同时改写图库；重扫会等待 MediaStore 数据流真正结束后才返回完成。
- **存储掉线不再误清图库**：SD 卡、外置卷未挂载或暂时不可用时，不再把该卷文件判定为已删除。
- **Android 10+ 不再依赖 `DATA` 判断搬家**：改用 scoped storage 可用的 `RELATIVE_PATH + DISPLAY_NAME`；字段缺失时保持原记录，不做猜测性删除。
- **取消宽泛路径删除**：移动文件后只允许删除精确的 content URI，不再按 `DATA` 跨媒体表删除，避免路径复用时误删新记录。
- **MediaScanner 重试不再阻塞线程**：改为可取消的挂起重试。
- **扩展名继续以原文件名为准**：即使 MediaStore 错报 `video/mp2t`，`video.mp4` 也不会变成 `.ts/.m2ts`。

### 防回归与构建

- 新增重扫并发回归测试、存储状态与 scoped-storage 路径策略单元测试。
- CI 改为仓库固定的 Flutter SDK 与 Gradle Wrapper，不再依赖此前下载失败的第三方 Flutter Action。
- CI 对 3 个 ABI 的 APK 检查包名、版本、versionCode、签名证书、ABI 纯度、ZIP 完整性和 SHA-256。
